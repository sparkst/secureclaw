# Article: How Prompt Injection Works

This article describes prompt injection at a high level for a general
audience. We avoid reproducing literal attack phrasing. Defenders should
focus on three layers: input filtering, prompt isolation, and output
review. Awareness training helps teams notice the structural features of
these attacks without needing to memorize specific trigger sentences.

A 2025 industry survey reported that prompt-injection-aware code review
significantly reduced incident rates across pilot programs.
